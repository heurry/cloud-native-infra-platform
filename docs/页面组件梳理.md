## 01 发现问题阶段

### 平台总览

**路由**: `/` (根路径)
**阶段徽章**: `stage-01 发现问题`
**文件**: `apps/web/src/pages/PlatformOverviewPage.tsx`

#### 使用的组件

| 组件名称 | 作用 | 数据来源 |
|---------|------|---------|
| **ClosedLoopRibbon** | 显示 AI Ops 闭环 6 阶段流程进度 | 静态配置 |
| **KpiGrid** | 展示平台核心指标（QPS、P95、TTFT、吞吐、错误率） | `/api/metrics/current` |
| **AlertCardComponent** | 8 个紧凑告警卡片，展示关键监控指标 | 计算自 metrics API |
| **QuickNavCard** | 快速跳转到其他 6 个页面的导航卡片 | 静态配置 |
| **PanelHeader** | 面板标题栏 | 本地组件 |

#### 功能说明

- **总览仪表板**：提供平台健康状态的一站式视图
- **快速导航**：通过卡片式导航跳转到闭环各阶段页面
- **告警聚合**：聚合展示 8 个核心指标的当前状态和告警级别
- **趋势提示**：每个 KPI 卡片显示数值、详情和告警色调

### 模型服务

**路由**: `/services`
**阶段徽章**: `stage-01 发现问题`
**文件**: `apps/web/src/pages/ServicesPage.tsx`

#### 使用的组件

| 组件名称 | 作用 | 数据来源 |
|---------|------|---------|
| **ClosedLoopRibbon** | 显示闭环流程，当前阶段为"发现问题" | 静态配置 |
| **KpiGrid** | 展示 Serving 指标（QPS、P95、TTFT、Tokens/s、错误率） | `/api/metrics/current` |
| **AlertCardComponent** | 8 个告警卡片：副本数、健康副本、QPS、延迟等 | metrics API |
| **DataTable** | 显示 vLLM 副本列表（副本名、健康、运行中、KV Cache、P95、吞吐） | `/api/metrics/current` → upstream_metrics |
| **诊断建议网格** | 基于指标阈值显示动态诊断建议 | 逻辑计算 |

#### 功能说明

- **Serving 监控**：实时展示模型服务的性能和健康状态
- **副本级监控**：列表展示每个 vLLM 副本的详细指标
- **智能诊断**：根据延迟、GPU 利用率等指标自动生成诊断建议
- **SLO 告警**：P95 > 200ms 或 TTFT > 80ms 时触发告警提示

#### 使用的组件

- **关联分析**：将应用层指标与基础设施层指标关联展示

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 5
- **图标库**: Lucide React
- **Markdown 渲染**: 自定义 MarkdownText 组件
- **样式**: 原生 CSS（无 CSS-in-JS，无 TailwindCSS）
- **状态管理**: React Hooks (useState, useEffect, useMemo)
- **数据获取**: Fetch API + SSE (Server-Sent Events)

## 设计原则

1. **紧凑高效**：所有页面内容在 1200px 高度视窗内无需滚动
2. **一致性**：统一的 5 层结构，相同的组件库，一致的视觉语言
3. **闭环驱动**：所有页面按 AI Ops 闭环阶段组织，逻辑清晰
4. **智能诊断**：基于指标阈值自动生成诊断建议，降低人工判断成本
5. **防御性设计**：长文本自动换行，防止溢出；错误边界保护；加载状态提示
