## 2. 架构原则（前端）

统一经 `apps/web/src/lib/api.ts` → Go `:8081`：

```
cd apps/web
VITE_PROXY_TARGET=http://127.0.0.1:8081 npm run dev
```

- Go 原生 `/api/*` 直连：health / platform/overview / service-instances(+healthcheck) / kubernetes(pods,deployments,snapshot) / metrics(current,history,requests) / config(items,versions,rollback) / deployments(+finish,rollback) / incidents(+ack,resolve) / audit/events / **ai(diagnose, diagnoses, diagnoses/{id}, chat:stream)**。
- Go legacy proxy 透传：`/api/aiops/* · /api/knowledge/* · /api/benchmarks/* · /api/models/* · /api/proxy/* · /api/chat/* · /api/evals/*`。
- **前端不感知任何旧服务地址**（Java/Python 单体/AI 服务）。缺字段先派生/snapshot；只有组合不出的关键业务字段才提案追加 Go DTO。
